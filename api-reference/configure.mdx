The `configure` function lets you supply WorkOS credentials and AuthKit options in code rather than relying solely on environment variables. This is especially useful in runtimes that do not expose `process.env` — such as Deno, Cloudflare Workers, or edge deployments — where you can pass a custom resolver function so AuthKit knows how to read environment values.

```typescript
import { configure } from '@workos-inc/authkit-remix';
```

## Overloads

`configure` is overloaded to accept a config object, a value-source function, or both together.

```typescript
// Overload 1 — programmatic config object
configure(config: Partial<AuthKitConfig>): void

// Overload 2 — custom environment variable source
configure(source: (key: string) => any): void

// Overload 3 — config object plus custom source
configure(config: Partial<AuthKitConfig>, source: (key: string) => any): void
```

## Parameters

### Overload 1 — `configure(config)`

<ParamField body="config" type="Partial<AuthKitConfig>" required>
  A partial configuration object. Only the keys you provide are applied; all other values fall back to environment variables or defaults. See [Configuration options](#configuration-options) below for the full list of accepted keys.
</ParamField>

### Overload 2 — `configure(source)`

<ParamField body="source" type="(key: string) => any" required>
  A function that receives an uppercase, underscore-separated environment variable name (e.g. `"WORKOS_API_KEY"`) and returns its value, or `undefined` if it is not set. Use this overload to integrate with runtimes that do not support `process.env`.
</ParamField>

### Overload 3 — `configure(config, source)`

<ParamField body="config" type="Partial<AuthKitConfig>" required>
  A partial configuration object applied on top of any values returned by `source`.
</ParamField>

<ParamField body="source" type="(key: string) => any" required>
  A custom environment variable resolver, identical to the one described in Overload 2.
</ParamField>

## Configuration options

The following keys are accepted by the `config` argument. Each key has a corresponding environment variable in the form `WORKOS_<SCREAMING_SNAKE_CASE>`.

| Key | Type | Required | Default | Environment variable | Description |
|---|---|---|---|---|---|
| `clientId` | `string` | ✅ | — | `WORKOS_CLIENT_ID` | Your WorkOS Client ID. |
| `apiKey` | `string` | ✅ | — | `WORKOS_API_KEY` | Your WorkOS secret API key. |
| `redirectUri` | `string` | ✅ | — | `WORKOS_REDIRECT_URI` | The absolute URL of your authentication callback route (e.g. `https://your-app.com/auth/callback`). |
| `cookiePassword` | `string` | ✅ | — | `WORKOS_COOKIE_PASSWORD` | Secret used to encrypt the session cookie. **Must be at least 32 characters.** |
| `cookieName` | `string` | ❌ | `"wos-session"` | `WORKOS_COOKIE_NAME` | Name of the session cookie set on the browser. |
| `cookieMaxAge` | `number` | ❌ | `34560000` (400 days) | `WORKOS_COOKIE_MAX_AGE` | Lifetime of the session cookie in seconds. The access and refresh tokens provide their own, shorter expiry windows. |
| `apiHostname` | `string` | ❌ | `"api.workos.com"` | `WORKOS_API_HOSTNAME` | Hostname of the WorkOS API. Override when using a proxy or local mock. |
| `apiHttps` | `boolean` | ❌ | `true` | `WORKOS_API_HTTPS` | Whether to use HTTPS for WorkOS API requests. Set to `false` for local development against a mock server. |
| `apiPort` | `number` | ❌ | — | `WORKOS_API_PORT` | Port for WorkOS API requests. Only needed when `apiHostname` points to a non-standard port. |
| `issuer` | `string \| string[]` | ❌ | — | `WORKOS_ISSUER` | Expected `iss` claim of WorkOS access tokens. Accepts a single string or an array. When omitted the issuer claim is not validated. Use a comma-separated string in the environment variable for multiple issuers. |

## Usage examples

### Overload 1 — Programmatic config object

Supply credentials directly when `process.env` is available but you prefer code-level configuration, or when you need to set values that have no corresponding environment variable.

```typescript
import { configure } from '@workos-inc/authkit-remix';

configure({
  clientId: 'client_01HQMJZD...',
  apiKey: 'sk-...',
  redirectUri: 'https://your-app.com/auth/callback',
  cookiePassword: 'a-very-long-secret-at-least-32-chars!!',
});
```

### Overload 2 — Custom environment variable source

Pass a resolver function for runtimes without `process.env`, such as Deno or Cloudflare Workers.

```typescript
import { configure } from '@workos-inc/authkit-remix';

// Deno
configure((key) => Deno.env.get(key));

// Cloudflare Workers (inside a handler or module initializer)
configure((key) => env[key]);
```

### Overload 3 — Config object plus custom source

Combine explicit overrides with a runtime-specific environment variable source.

```typescript
import { configure } from '@workos-inc/authkit-remix';

// Provide a fallback source for any keys not set in the config object
configure(
  { clientId: 'client_01HQMJZD...' },
  (key) => Deno.env.get(key),
);
```

<Note>
  `configure()` should be called before any routes process requests — typically at application startup (e.g. the top of your `entry.server.tsx` or a dedicated `app/config.server.ts` module that is imported early).
</Note>

<Warning>
  `cookiePassword` must be at least 32 characters. If a shorter value is passed, `configure()` immediately throws an `Error`. Generate a strong password with a command such as `openssl rand -base64 32`.
</Warning>
